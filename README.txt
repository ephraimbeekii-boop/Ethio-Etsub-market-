How to publish using GitHub Pages on an Android phone:
1. Open github.com in Chrome and sign in.
2. Open the repository you already created for this website.
3. On the repository page, tap Add file (or the + menu) > Create new file.
4. Name the file exactly: index.html
5. Open this supplied index.html file in a text editor, copy all its contents, and paste them into GitHub's editor.
6. Scroll down, tap Commit changes, and confirm.
7. In the repository, open Settings > Pages.
8. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
9. Wait a few minutes. The Pages settings screen will show your published website address.

Important:
- This is a front-end demo. Products added in the form are not permanently saved.
- A selected video is only previewed on the current phone/browser; it is not uploaded to a server.
- To let every visitor upload/watch videos, you will need a backend/storage service and upload limits/security.
- Replace sample products and add your business contact details before sharing the public site.
